# navcode
> Codebase intelligence layer for AI coding agents

## Install
```bash
pip install navcode
```

## Usage
```bash
navcode init --claude
navcode init --cursor
navcode init --bob
navcode init --auto
```

## Supported Agents
Claude Code, Cursor, IBM Bob, Codex, Copilot,
Kimi, Antigravity, Windsurf, Continue

## How it works
navcode indexes your codebase locally and feeds only
relevant context to AI agents — reducing token usage by 80-90%.
